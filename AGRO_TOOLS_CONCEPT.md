# Agro Tools --- концепция проекта

## Идея

**Agro Tools** --- цифровой полевой помощник агронома: приложение для
быстрых расчётов, полевых наблюдений и ведения истории работ по каждому
полю.

Первая версия разрабатывается на Python как локальное приложение/CLI.
Расчётная логика отделяется от интерфейса, чтобы в дальнейшем её можно
было использовать при создании Android-приложения.

## Основные принципы

-   Расчётная логика не зависит от интерфейса.
-   Каждый агрономический блок находится в отдельном модуле.
-   Сначала реализуются простые и практически полезные полевые функции.
-   Расчёты должны быть прозрачными и проверяемыми.
-   Источником норм применения СЗР, удобрений и других регулируемых
    параметров остаются этикетка/регламент препарата, агрономические
    рекомендации и местные требования.
-   В дальнейшем расчёты связываются с конкретными полями и сохраняются
    в историю операций.

## 1. Посев

Модуль для расчётов, связанных с посевом.

### Планируемые функции

-   расчёт нормы высева, кг/га;
-   расчёт количества семян на гектар и м²;
-   пересчёт кг/га ↔ млн семян/га;
-   учёт массы 1000 семян;
-   учёт лабораторной всхожести;
-   учёт чистоты семян;
-   расчёт общей потребности семян на поле;
-   обратный расчёт фактической густоты при известной норме высева;
-   оценка фактической густоты растений по результатам полевого учёта.

## 2. Опрыскивание

Полевой калькулятор для приготовления рабочего раствора и планирования
заправок.

### Планируемые функции

-   количество препарата на всё поле;
-   необходимый объём рабочего раствора;
-   площадь обработки одним баком;
-   количество препарата на полный бак;
-   количество полных и неполных заправок;
-   расчёт последней неполной заправки;
-   баковые смеси из нескольких компонентов;
-   поддержка норм в л/га, мл/га, кг/га, г/га;
-   в дальнейшем --- расчёты для калибровки опрыскивателя.

### Возможное расширение

-   рабочая скорость;
-   ширина захвата;
-   расход форсунок;
-   фактический расход рабочего раствора;
-   журнал обработок.

## 3. Удобрения

Калькулятор физической массы удобрений и действующего вещества.

### Планируемые функции

-   требуемая физическая масса удобрения по норме действующего вещества;
-   расчёт внесения N, P₂O₅ и K₂O;
-   обратный расчёт: сколько действующего вещества внесено при заданной
    физической норме;
-   потребность удобрения на всё поле;
-   смеси нескольких удобрений;
-   сохранение внесения в историю поля.

Пример задачи:

> Требуется внести 80 кг N/га. Имеется карбамид с содержанием 46% N.
> Приложение рассчитывает необходимую физическую норму карбамида и общее
> количество на поле.

## 4. Поле и техника

Быстрые расчёты для выполнения полевых работ.

### Планируемые функции

-   площадь поля;
-   ширина захвата;
-   рабочая скорость;
-   производительность, га/ч;
-   ориентировочное время выполнения работы;
-   расход материала на гектар и поле;
-   остаток материала до завершения поля;
-   в дальнейшем --- расход топлива.

## 5. Полевые обследования

Этот раздел должен постепенно превратить Agro Tools из калькулятора в
полноценный полевой журнал.

### Для каждого обследования

-   поле;
-   культура;
-   дата;
-   фаза развития;
-   густота растений;
-   сорняки;
-   вредители;
-   признаки болезней;
-   повреждения;
-   текстовые заметки;
-   фотографии.

В Android-версии:

-   GPS-координаты точки обследования;
-   фотографии с камеры;
-   отображение точек на карте;
-   повторное посещение сохранённых точек.

## 6. Урожайность и потери

### Планируемые функции

-   предварительная оценка урожайности;
-   расчёты по элементам структуры урожая;
-   пересчёт массы урожая к стандартной влажности;
-   фактическая урожайность, т/га;
-   оценка потерь при уборке;
-   отдельные методики расчёта для разных культур.

## 7. Мои поля

В перспективе это центральный раздел приложения.

Для каждого поля хранится карточка:

-   название/номер поля;
-   площадь;
-   культура;
-   сорт/гибрид;
-   дата и параметры посева;
-   история обследований;
-   внесение удобрений;
-   обработки СЗР;
-   фотографии и заметки;
-   результаты уборки.

Пример истории:

``` text
Поле №12
Площадь: 86.4 га
Культура: озимая пшеница

12.09 — Посев
04.10 — Обследование
18.03 — Внесение азотного удобрения
02.05 — Гербицидная обработка
16.05 — Обследование
...
```

Расчёт из любого модуля в дальнейшем можно будет сохранить как операцию
конкретного поля.

## 8. Погода --- поздний этап

Погодный модуль имеет смысл добавить после появления интерфейса и работы
с API.

Возможные данные:

-   температура;
-   осадки;
-   скорость и направление ветра;
-   влажность воздуха;
-   прогноз;
-   история погодных условий во время выполнения операций.

Погода может быть связана с полем, обследованиями и журналом операций.

## Архитектура Python-версии

На первом этапе:

``` text
agro-tools/
├── src/
│   └── agro_tools/
│       ├── __init__.py
│       ├── main.py
│       ├── seeding.py
│       ├── spraying.py
│       ├── fertilizer.py
│       ├── field.py
│       ├── yield_calc.py
│       └── conversions.py
├── tests/
├── pyproject.toml
├── README.md
└── uv.lock
```

Расчётные модули не должны зависеть от конкретного пользовательского
интерфейса.

Условная схема:

``` text
Интерфейс
    ↓
Presenter / прикладная логика
    ↓
Агрономические расчёты и модели
    ↓
Хранение данных
```

Сначала интерфейс будет консольным. Позже его можно заменить
Android-интерфейсом, сохранив максимально возможную часть проверенной
бизнес-логики и формул.

## Этапы разработки

### MVP 1 --- Полевые калькуляторы

1.  Посев.
2.  Опрыскивание.
3.  Удобрения.
4.  Поле и техника.
5.  Тесты для основных формул.

### MVP 2 --- Полевой журнал

1.  Карточки полей.
2.  История операций.
3.  Полевые обследования.
4.  Сохранение результатов расчётов.
5.  Локальная база данных.

### MVP 3 --- Мобильное приложение

1.  Android-интерфейс.
2.  GPS.
3.  Камера и фотографии.
4.  Работа офлайн.
5.  Синхронизация данных при необходимости.

### Поздние расширения

-   погодные API;
-   карты;
-   импорт/экспорт CSV и Excel;
-   отчёты;
-   дополнительные расчёты для конкретных культур;
-   синхронизация между устройствами.

## Цель проекта

Сделать не просто набор агрономических калькуляторов, а **полевой
инструмент, в котором расчёты, наблюдения и история работ связаны с
конкретным полем**.

На первом этапе главное --- получить небольшой, надёжный и понятный
инструмент. Новые функции добавляются только тогда, когда понятно, какую
практическую полевую задачу они решают.
